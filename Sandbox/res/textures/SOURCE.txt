Texture sources
===============

All files here come from ambientCG (https://ambientcg.com) and are released under
CC0 1.0 Universal (public domain). No attribution is required; this file records
provenance so it is obvious where they came from and that they are safe to ship.

  paving_*.jpg   <- PavingStones092, 1K JPG
  bricks_*.jpg   <- Bricks075A, 1K JPG

Each set uses three of the maps from the original download:

  *_color.jpg      <- _Color         sRGB, the albedo
  *_normal.jpg     <- _NormalGL      linear, OpenGL convention (+Y up)
  *_roughness.jpg  <- _Roughness     linear, greyscale

NormalGL rather than NormalDX: the shader's tangent frame expects +Y up, and the
DirectX variant has green inverted, which would light every bump from the wrong side.

The roughness map is fed to the engine as the metallic-roughness texture. That works
because the file is greyscale (R=G=B) and the shader reads roughness from G and
metallic from B, then multiplies both by the material's scalars — so a material with
metallic = 0 ignores the blue channel entirely. For a metal, this shortcut would be
wrong and the map would have to be packed properly (roughness into G, metallic into B).

The unused maps from the originals (AmbientOcclusion, Displacement, NormalDX) were
left out to keep the repository small.
