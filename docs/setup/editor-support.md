# Editor support

`res/layouts/tsconfig.json` exists so a typo in a layout is a red squiggle rather than a
message from the build:

```json
{
  "compilerOptions": {
    "noEmit": true, "strict": true, "target": "ES2020", "module": "ESNext",
    "moduleResolution": "bundler", "jsx": "react", "jsxFactory": "h",
    "types": [], "skipLibCheck": true
  },
  "include": ["rda.d.ts", "*.tsx", "../themes/*.ts"]
}
```

Nothing emits from it. esbuild does the transform, and the layout compiler refuses an
unknown widget or property whether or not anyone ran `tsc` — which is the check that
actually gates anything. Run it by hand with:

```bash
node_modules/.bin/tsc -p MyApp/res/layouts
```

`rda.d.ts` is generated by `rda_add_types` from three things — the widget schema in the
toolchain, your theme's variants, and your state declaration — so it follows all three. A
committed `.d.ts` that has drifted is worse than none: it reports errors that are not real
and misses ones that are. Let the build regenerate it.
