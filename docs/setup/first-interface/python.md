# Your first interface, in Python

The three files under `res/` are on [the previous page](README.md); what sits beside them
is [a Python project](../adding-to-a-project/python.md). This is the one file left.

## `app.py`

```python
import rda
from state import State, Commands, define    # generated by `python -m rda build .`

config = rda.StartupConfig()
config.name = "My application"
config.theme = "res/themes/app.rdth"

@Commands.save
def on_save():
    print("saving:", State.notes)

@config.on_start
def opened():
    define()                                  # the names, before the layout
    rda.load_interface("res/layouts/home.rdab", "res/layouts/home.tsx")

rda.init(config)
rda.wait()
```

`state.py` was generated from `res/state.ts`, and every signal on `State` is a real
property with the type and documentation the declaration gave it. `State.notAThing = 1`
is an `AttributeError` where it is written, not a value that quietly stays zero.

`@Commands.save` at module level runs at import, before the engine exists and before the
declaration has created the command. That is fine: the binding remembers it and applies
it once `on_start` has declared the names.

The second argument to `load_interface` is the layout's source. A Debug engine watches
it, and recompiles the blueprint when you save — which is what makes the edit at the end
of the previous page rebuild the screen in place.

`init()` returns with the engine running on its own thread, so the interpreter stays
yours — a REPL, a web server, a data pipeline carries on while the window is open.
`wait()` is for when there is nothing left to do but let it live.

## Run it

```bash
python -m rda build .
python app.py
```

From the project directory. The first line compiles the theme and the layout beside
their sources and writes `state.py`; the second opens the window. Nothing else is built:
`import rda` is the package in the engine checkout, and it opens the engine from the
checkout's `bin/`. If that import fails, the bring-up has not run for this interpreter —
`python <checkout>/bindings/python/register.py` is the one line it would have run.

Press *Save* and the console prints whatever is in the field.
